# AD Draft AutoShot B: коррекция свапов через Steam Web API

Идея та же, что у AutoShot: скриншот драфта делается автоматически в момент,
когда игра переключается на STRATEGY TIME. **Новое в B:** игроки могут
поменяться героями и после этого (во время strategy time и в pre-game вплоть
до рожка). Доска на экране в этот момент ломается (ники пропадают, модели
меняются), поэтому скриншот по-прежнему делается сразу в начале strategy
time. Дальше версия B каждые несколько секунд до рожка забирает **живой
состав матча из API Valve**, и когда два игрока поменялись героями, **меняет
их ники местами прямо внутри `screenshot.png`**. Оверлей смотрит на тот же
файл и просто показывает исправленную доску.

Чистый Windows PowerShell (Windows 10/11), ничего ставить не нужно. Что нужно:

- **Steam Web API key** (бесплатно, минута): https://steamcommunity.com/dev/apikey
  (домен любой, например `localhost`; аккаунт Steam не должен быть
  ограниченным)
- профиль Steam с **публичными "Game details"** (Профиль > Редактировать >
  Настройки приватности). Так инструмент находит игровой сервер твоего матча.
  Если не хочешь открывать, впиши в конфиг steam64 тиммейта, у которого это
  открыто (`ExtraSteamIds`).
- язык интерфейса Dota английский (доска читается по тексту, чтобы понять,
  какая карточка какому герою принадлежит)

## Файлы

- `autoshot-b.ps1`: слушатель (скриншот + слежение за составом)
- `start_autoshot-b.bat`: запускает его. Единственное, что нужно запускать.
- `autoshot-b.config.example.json`: скопируй в `autoshot-b.config.json` и вставь ключ
- `heroes.json`: список героев (id и имена)
- `gamestate_integration_autoshot.cfg`: конфиг Dota (кладётся в папку Dota, см. ниже). В версии B он дополнительно сообщает твой steam id, чтобы инструмент сам находил твой матч.

Стандартная версия лежит на папку выше; запускать только один
из двух слушателей (оба используют порт 3211).

## Установка

1. Положи папку в постоянное место, например `C:\screenshot\`. Источники
   "Изображение" в Streamlabs / OBS указывают на `screenshot.png` в этой папке
   (как и раньше).
2. Скопируй `autoshot-b.config.example.json` в `autoshot-b.config.json` и
   вставь ключ в `SteamApiKey`.
3. Конфиг Dota (один раз): Steam > Библиотека > ПКМ по Dota 2 > Управление >
   Посмотреть локальные файлы, затем `game\dota\cfg\gamestate_integration\`
   (создай папку, если её нет). Скопируй туда
   `gamestate_integration_autoshot.cfg` ИЗ ЭТОЙ ПАПКИ (перезапиши файл стандартной версии, в новом на
   одну строку больше). Перезапусти Dota, если была запущена.
4. Двойной клик по `start_autoshot-b.bat`. Окно оставь открытым (можно
   свернуть).

Dota на основном мониторе, желательно 16:9 (1080p, 1440p, 4K). Borderless
Window, если скриншоты чёрные.

`debug_board.png` показывает, что прочитано на доске (жёлтая рамка = имя
героя, голубая = полоса с ником, которая меняется местами).

## Как определяется свап

- Доска читается один раз при снимке: какой герой на какой карточке.
- Первый полный состав из API (10 игроков, у всех есть герой) становится
  базой: кто что задрафтил.
- Каждые 5 секунд состав забирается снова. Если два игрока одной команды
  теперь держат героев друг друга, это свап: две полосы с никами на доске
  меняются местами попиксельно, каждый раз начиная с нетронутого снимка.
  Ничего не перерисовывается, выглядит ровно так, как отрисовала игра. Свап
  обратно тоже обрабатывается.
- Последняя проверка через несколько секунд после рожка, затем слежение
  останавливается до следующего драфта.

Свап, завершённый до получения базового состава (первые ~2 секунды strategy
time), неотличим от драфта и не исправляется. Карточка, имя героя на которой
не прочиталось, выводится в консоль; свапы с её участием логируются, но не
исправляются. Неанглийский интерфейс: поставь
`"AssumeBoardOrderMatchesRoster": true`, если в твоих играх порядок карточек
на доске всегда совпадает с порядком слотов команды из API; тогда чтение
текста не нужно.

## Калибровка

Запусти из окна PowerShell в папке, пока на экране STRATEGY TIME (подойдёт
матч с ботами):

```
powershell -ExecutionPolicy Bypass -File .\autoshot-b.ps1 -Calibrate
```

Через 3 секунды делается снимок, пишется `calibration.png` с рамками и в
консоль выводятся десять прочитанных имён героев. Жёлтые рамки должны
накрывать имена героев, голубые - ники. Если съехали, переопредели числа в
`autoshot-b.config.json`:

```json
{ "HudCenterOffset": 0, "Layout": { "RowTop0": 0.1426, "RowPitch": 0.1562 } }
```

Все числа раскладки - доли высоты экрана, x относительно центра экрана.
Любой ключ из блока `$L` в начале скрипта можно переопределить.

## Если что-то не работает

- **Консоль молчит во время игры**: конфиг не в той папке, или Dota не перезапускали.
- **"match server not found yet" без конца**: Game details не публичные, или Steam ещё не зарегистрировал матч. Открой их или добавь steam64 тиммейта в `ExtraSteamIds`.
- **"roster not complete yet" без конца**: API иногда отстаёт на несколько секунд после драфта; если так и не заполняется, матч не на сервере Valve (кастомные лобби на локальных серверах не поддерживаются).
- **"Windows OCR not available"**: Параметры > Время и язык > Язык > добавить English (United States) с функцией OCR / "Basic typing".
- **Порт занят**: поменяй `$Port` в начале `autoshot-b.ps1` и в .cfg.
