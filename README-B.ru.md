# AD Draft AutoShot B: версия с учётом свапов героев

Идея та же, что у AutoShot: скриншот драфта делается автоматически в момент,
когда игра переключается на STRATEGY TIME. **Новое в B:** игроки могут
поменяться героями и после этого (strategy time, pre-game, вплоть до
рожка), и тогда на оверлее стоят не те ники. Версия B следит за портретами
героев в верхней панели до самого рожка, и когда два игрока меняются героями,
**меняет их ники местами прямо внутри `screenshot.png`**. Оверлей смотрит на
тот же файл и просто показывает исправленную доску.

Без API-ключа, без аккаунтов, ничего ставить не нужно. Чистый Windows
PowerShell (Windows 10/11). Портреты героев для сравнения один раз
скачиваются с CDN Valve (около 8 МБ) в `%LOCALAPPDATA%\ad-draft-autoshot`.

## Файлы

- `autoshot-b.ps1`: слушатель (скриншот + слежение за свапами)
- `start_autoshot-b.bat`: запускает его. Единственное, что нужно запускать.
- `heroes.json`: список героев для чтения доски
- `gamestate_integration_autoshot.cfg`: конфиг Dota, тот же, что у версии A (кладётся в папку Dota, см. ниже)

Оригинальный `autoshot.ps1` можно оставить в папке, но запускать только один
из двух слушателей (оба используют порт 3211).

## Установка

1. Положи папку в постоянное место, например `C:\screenshot\`. Источники
   "Изображение" в Streamlabs / OBS указывают на `screenshot.png` в этой папке
   (как и раньше, для существующих настроек ничего не меняется).
2. Конфиг Dota (один раз): Steam > Библиотека > ПКМ по Dota 2 > Управление >
   Посмотреть локальные файлы, затем `game\dota\cfg\gamestate_integration\`
   (создай папку, если её нет). Скопируй туда
   `gamestate_integration_autoshot.cfg`. Перезапусти Dota, если была запущена.
3. Двойной клик по `start_autoshot-b.bat`. Окно оставь открытым (можно
   свернуть). При первом запуске скачаются портреты героев.

Требования для коррекции свапов (сам скриншот работает всегда):

- Язык интерфейса Dota **английский** (доска читается по тексту: "PUDGE",
  "STORM SPIRIT"...). Подходит любой языковой пакет OCR Windows с латиницей;
  Windows ставит его вместе с языком системы.
- Dota на основном мониторе, желательно 16:9 (1080p, 1440p, 4K). Другие
  пропорции: запусти калибровку ниже и проверь рамки.
- Режим Borderless Window, если скриншоты чёрные.

```

...
[20:02:40] pre-game: watching the top bar for hero swaps every 3 s
[20:02:42] top bar baseline (10/10): R: sniper, tinker, ...  |  D: kunkka, ...
[20:03:04] SWAP detected: the player who drafted sniper now plays primal_beast (and vice versa) -> names exchanged on the board
```

`screenshot.base.png`: нетронутый снимок, `screenshot.png`: исправленный.
`debug_board.png` / `debug_topbar.png` показывают, что было прочитано
(жёлтая рамка = имя героя, голубая = полоса с ником, которая меняется
местами, зелёная = распознанный портрет, красная = не распознан).

## Калибровка (один раз, или если что-то не распознаётся)

Запусти из окна PowerShell в папке, во время игры (после рожка тоже подходит,
любой режим, главное чтобы верхняя панель была видна):

```
powershell -ExecutionPolicy Bypass -File .\autoshot-b.ps1 -Calibrate
```

Через 3 секунды делается снимок, пишется `calibration.png` со всеми рамками
и в консоль выводятся десять распознанных героев. Зелёные рамки должны лежать
на десяти портретах. Для проверки доски запусти ту же команду на экране
STRATEGY TIME: жёлтые рамки должны накрывать имена героев, голубые - ники, а
консоль показать десять прочитанных имён.

Если рамки съехали, создай рядом со скриптом `autoshot-b.config.json`:

```json
{
  "HudCenterOffset": 0,
  "Layout": { "TopRadiantX": -0.386, "TopDireX": 0.102, "TopPitch": 0.0578 }
}
```

Все числа - доли высоты экрана, x относительно центра экрана. Любой ключ из
блока `$L` в начале скрипта можно переопределить здесь, а также `PollSec`,
`MinSlotScore`, `DebugImages` и т.д.

## Как определяется свап

- Доска читается один раз при снимке: какой герой на какой карточке.
- С начала pre-game десять портретов верхней панели каждые 3 секунды
  сравниваются с артами героев. Первое чистое чтение (не меньше 8 из 10
  героев, без дублей) становится базой.
- Dota разрешает свап только внутри команды, поэтому свап выглядит как два
  портрета одной команды, поменявшихся местами. Он должен подтвердиться в
  двух чтениях подряд, прежде чем применится.
- Коррекция = две полосы с никами на доске меняются местами попиксельно,
  каждый раз начиная с нетронутого снимка. Ничего не перерисовывается,
  выглядит ровно так, как отрисовала игра.
- Последнее чтение сразу после рожка, затем слежение останавливается до
  следующего драфта.

Ограничения: свап, завершившийся в первую секунду pre-game до базового
чтения, не будет замечен. Карточка, имя героя на которой не прочиталось,
выводится в консоль; свапы с её участием логируются, но не исправляются.
Неанглийский интерфейс: если в твоих играх порядок карточек на доске всегда
совпадает с порядком в верхней панели, поставь в конфиге
`"AssumeBoardOrderMatchesTopBar": true`, тогда чтение текста не нужно вообще.

## Если что-то не работает

- **Консоль молчит во время игры**: конфиг не в той папке, или Dota не перезапускали.
- **"Windows OCR not available"**: Параметры > Время и язык > Язык > добавить English (United States) с функцией OCR / "Basic typing".
- **Портреты не распознаются (все рамки красные в `debug_topbar.png`)**: запусти `-Calibrate` и поправь числа раскладки, или задай `HudCenterOffset`, если HUD не по центру (второй монитор, свой масштаб HUD).
- **Порт занят**: поменяй `$Port` в начале `autoshot-b.ps1` и в .cfg.
